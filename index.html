Paramètres & Configuration

🗄️ Base de données (Supabase)

Connectez l'outil à votre projet Supabase pour centraliser les données (au lieu du navigateur). Renseignez l'URL du projet et la clé anon/public. Une table app_state est requise (script SQL fourni).

⚙️ Configuration (Setup)

📋 Les lignes budgétaires se configurent désormais province par province, dans la carte « Lignes budgétaires » ci-dessous (choisissez la province active en haut de l'écran).

📋 Lignes budgétaires

Propres à la province active (sélecteur en haut de l'écran). Proposées automatiquement dans les formulaires des avances et des activités de cette province uniquement. Une ligne par rangée.
